# 03. 와이어프레임

> 텍스트 와이어프레임. 비율은 데스크톱 ≥1280px 기준 12컬럼 그리드, 모바일은 각 페이지 끝에 변형 규칙만 기술.
> `▸`는 딥링크, `ⓘ`는 Provenance 팝오버(출처/근거), `[ ]`는 인터랙티브 컨트롤.

## 0. 앱 셸

```
┌────────────┬──────────────────────────────────────────────────────────────┐
│            │  페이지 타이틀            ····· 페이지 헤더 컨트롤 ·····  ◷    │
│  MyLedge   │  (기간 컨트롤 / 기준 모드 / 스냅샷 메타 — 페이지가 정의)        │
│            ├──────────────────────────────────────────────────────────────┤
│  ◉ 홈      │                                                              │
│  ◎ 지출    │                                                              │
│  ◎ 자산·부채│                    페이지 컨텐츠                              │
│  ◎ 신호    │              (max-width 1280, 중앙 정렬)                      │
│  ────────  │                                                              │
│  ◎ 데이터  │                                                              │
│   · 인박스 ⑫│                                                             │
│   · 거래   │                                                              │
│   · 대출   │                                                              │
│   · 할부   │                                                              │
│   · 자산메타│                                                             │
│   · 규칙   │                                                              │
│   · 가져오기│                                                             │
│   · 데이터사전                                                            │
│  ────────  │                                                              │
│  ⚠ 읽기전용 │   ← API 키 없을 때만. 클릭 시 설명 팝오버                     │
└────────────┴──────────────────────────────────────────────────────────────┘
```

- 사이드바 240px 고정, `데이터` 하위는 데이터 페이지 진입 시 펼침. 인박스에 처리 대기 수 배지(`⑫`).
- 페이지 헤더는 sticky. 기존 "메타 배지"(기준일/건수)는 페이지 헤더 우측 슬롯으로 흡수.
- read-only는 사이드바 하단 1곳 + 비활성 컨트롤 hover 툴팁("API 키가 없어 저장할 수 없습니다")으로 통일. 페이지별 경고 배너 제거.

**모바일 (<768px):** 사이드바 → 하단 탭바 5개(홈/지출/자산/신호/데이터) + 데이터 내부는 상단 가로 스크롤 칩. 페이지 헤더 컨트롤은 시트(bottom sheet)로 접힘.

- 전역 기간이 모든 렌즈와 거래 내역에 적용. 로컬 예외(MoM 기준월, 달력 월)는 `전역과 다름 ●` 점 표시.

**모바일:** 렌즈 탭 가로 스크롤, 거래 내역은 "내역 보기" 버튼 → 풀스크린 시트.
